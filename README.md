# Niri OS

Эмулятор мобильной операционной системы Niri OS, который работает прямо в браузере.

Откройте `index.html` в любом браузере. Внутри: экран загрузки и блокировки, главный экран с док-панелью,
пункт управления, недавние приложения, светлая и тёмная тема, обои и 12 приложений
(Телефон, Сообщения с помощником Нири, Обзор, Настройки, Калькулятор, Заметки, Часы, Погода,
Галерея, Музыка, Змейка, Файлы).

Управление: свайп вверх на экране блокировки, клик по строке состояния для пункта управления,
`Esc` назад, `H` домой, `R` недавние.
